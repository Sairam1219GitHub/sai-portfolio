# Portfolio Website - B Sai Ram

A modern, responsive portfolio website built with Next.js, React, and Tailwind CSS.

## Features

- 🎨 Modern and responsive design
- ⚡ Fast performance with Next.js
- 📱 Mobile-first approach
- 🎯 Smooth scrolling navigation
- 💼 Showcases skills, experience, and projects
- 📧 Contact information and social links

## Technologies Used

- **Framework**: Next.js 14
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Icons**: React Icons

## Getting Started

### Prerequisites

- Node.js 18+ installed
- npm or yarn package manager

### Installation

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build for Production

```bash
npm run build
npm start
```

## Customization

You can easily customize the portfolio by editing the component files in the `components/` directory. Each section is modular and can be updated independently.
