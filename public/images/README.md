# Profile Photo Instructions

To add your profile photo:

1. Extract the image from `my_photo.pdf` (you can use online PDF to image converters or screenshot tools)
2. Save the image as `profile-photo.jpg` in this folder (`public/images/`)
3. Recommended image specifications:
   - Format: JPG or PNG
   - Size: At least 600x600 pixels (square format works best for the rounded frame)
   - File size: Under 500KB for optimal loading
   - Professional headshot with good lighting

The image will automatically appear in the Hero section on the left side with a beautiful blue glow effect and rounded frame.

**Supported file names:**
- `profile-photo.jpg` (recommended)
- `profile-photo.png`
- `photo.jpg`
- `photo.png`

If you want to use a different filename, update the `src` attribute in `components/Hero.tsx`.
